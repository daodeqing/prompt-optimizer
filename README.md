# 提示词优化器 1.4.0

把原始想法整理成清晰、可复制的 AI 提示词，也能在插件内选择模型、推理强度并比较模型表现。

## 1.4.0 新功能与配置

在插件详情页的“模型与推理强度”选择模型来源、型号和真实支持的推理档位，然后点击“保存配置”。工作台的“优化模型”和测试区共用这份配置；没有强度档位的模型保持“未指定”。Fast 是单独的设置，按宿主能力提供，不会静默换模。当前仅支持插件执行电脑的本机模型，不管理或轮换 CPA 凭证。

模型降智测试在工作台下方，独立于项目选择：

| 类型 | 次数 / 版本 | 展示结果 |
| --- | --- | --- |
| 糖果题 | 1、3、5 次，聊天支持 1–5 次 | 逐轮最终整数答案、理由、通过率及无法评分/请求失败 |
| 数字指纹 | 固定 3 组随机数字挑战 | 本地 LM Detector 算法的候选模型、家族及前五名；样本不足三组不给概率 |
| 画鹈鹕 | 原版 HTML 动画、多合一 SVG | 骑车鹈鹕画面、原始代码、复制和耗时，供人工比较构图与指令遵循 |
| SIWC | 当前接口不支持 | 说明所缺的 CPA SIWC 凭证绑定与专用通道，不伪造可用结论 |

测试区直接选择模型和推理强度后，先点击“保存模型与强度”，再“开始测试”。展开题目查看题面；展开逐轮结果查看原始回答、耗时和宿主接受的配置。“最近 20 次测试”可加载历史，未完成请求可“继续查看”或取消；状态未知时不要新建请求。关闭页面保留原编号和记录。

### 费用与结果边界

糖果题每轮一个独立模型任务，指纹每次三个任务，画鹈鹕每次一个任务，按所选模型正常消耗额度。插件不自动重试失败或无效回答，查询原请求不重复已提交轮次。Cindy 系统上下文、推理与供应商路由会增加 Token；费用以供应商账单为准。取消不保证返还已产生费用。

糖果题答对或答错均不能单独证明账号降智。指纹概率只在固定参考库候选之间归因，不能验证真实模型身份；未知模型、近似模型和采样差异都可能造成偏移。Cindy 任务自带系统上下文，参考挑战的 system 部分在本插件作为用户层题面发送，与原库采样不同。画鹈鹕没有客观通过率，由用户人工判断。

画面在空 sandbox iframe 中预览，并用 CSP 禁止脚本、联网、表单和外部资源。SVG/CSS 动画可以显示，依赖 JavaScript 的动画不会执行；需要完整脚本动画时可复制原始代码，经审阅后自行打开。

SIWC 需要 CPA 的逐凭证 OAuth 绑定、启用状态和相应请求通道，当前 Cindy 模型目录不暴露这些信息。普通模型请求成功不能当作 SIWC 检测成功。

## 主要功能

- **结合项目上下文改写提示词**：自动只读筛选所选项目内的代码、文档与文字型 PDF（内置 Mozilla PDF.js 本地提取文字并保留页码），并在同一次任务中通过 Cindy 官方历史工具检索本项目相关会话，只生成可复制的成品提示词，不直接执行原任务或改动项目文件。
- **分类与篇幅可控**：支持工程、编程、论文/研究、写作、分析 5 类任务（默认自动识别，也可手选），以及自动、精简、标准、详细 4 档篇幅；本身清晰的请求只做必要润色，不强套冗长模板。
- **锁定所选模型与单份干净交付**：首次选择并保存优化模型后，工作台与聊天调用严格沿用同一来源、型号与推理强度，不静默降级或换型。聊天调用默认通过结果卡单份交付成品提示词，避免与外层助手重复输出；卡片不可见时支持按原请求编号纯文本交付。
- **糖果题模型降智测试**：工作台（1/3/5 次）与 `candy_test` 工具（1–5 次）可使用已保存模型独立闭卷运行糖果题测试，按最终答案是否为 21 结构化评分，展示通过率、单次答案、耗时与最近 20 次测试历史。

## 使用步骤

1. 打开插件工作台，点击“选择项目”。
2. 首次选择并保存优化模型，之后聊天与工作台始终沿用该来源和型号。
3. 输入原始提示词，点击“优化提示词”，完成后点击“复制”；或点击“降智测试”检测当前模型状态。

## 降智测试说明

每次测试均为独立闭卷任务，模型须返回 `final_answer` 和 `reason`；插件按最终 `final_answer` 是否为 `21` 评分，逐次显示通过、未通过、无法评分或请求失败，并保留模型、来源、推理强度和耗时。测试不读取项目资料，也不执行用户任务。`21` 依赖原题“不同形状靠手感可以分辨”的前提；账号权限、模型波动、系统上下文和供应商路由都会影响结果，单题错误或单次低通过率不能单独证明账号被降智。

## 项目资料、PDF 与会话边界

PDF 支持文字层提取，不包含 OCR：扫描件/无文字页面会提示需要 OCR；加密 PDF 提示先解锁，损坏文件明确提示解析失败。每个 PDF 上限 12 MiB、80 页、220000 字符；一次最多解析 12 份、总输入不超过 32 MiB。超限会显示截取或未读状态。PDF 不执行文档脚本、不追踪外部链接，也不联网下载字体。

项目会话由已保存模型在同一次优化任务中，通过 Cindy 内置 `cindy_helper` 的 `search_chat_history`/`get_chat_history` 查询，限定所选项目的 `workdir`、本机与用户/助手记录；不直接读取宿主数据库。插件核对真实工具回执，界面分别显示已读取、查询成功但无具体引用、无结果和不可用。隐藏目录、依赖、构建产物、常见凭据文件及项目外符号链接默认排除。

## Token、预算与恢复

本地扫描最多查看 6000 个目录项、检查 200 个候选、成功读取 100 份资料或约 2 MB 文本，再返回最多 36000 字符候选片段。进入模型的字符预算按任务收缩（简单默认约 4500、精简约 3500、复杂自动约 12000、详细约 18000，另受宿主输入总长度限制）。实际 Token、缓存与费用以供应商账单为准，已保存模型不可用时停止，不静默换型号。

每次请求保存稳定编号、模型和资料快照。超时或状态未知时点击“继续查看”或调用 `query_optimization`/`query_candy_test` 查询原编号，不重复提交计费。
